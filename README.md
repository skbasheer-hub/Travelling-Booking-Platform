# Travelling-Booking-Platform
A simple yet functional Travel Booking Application built using Java, JDBC, Oracle Database, HTML, CSS, and JavaScript.
This project demonstrates full-stack development concepts including UI design, backend logic, database connectivity, validations, and modular programming.

🚀 Features

🔎 Search Travel Destinations

🎫 Book Travel Packages

👤 User Input Validation

📦 Modular Code Structure

🗄️ Database Connectivity using JDBC & Oracle

⚠️ Error/Exception Handling

📊 Improved Performance with Optimized Queries

Frontend:

HTML

CSS

JavaScript

Backend:

Java
